# 信源网络可达性验证报告

测试日期：2026-09-29（北京时间）。范围仅为网络、列表字段和抽样正文预检；未开发政策筛选、AI、网站或定时采集。

## 方法与环境

- 本地：用户本机 Windows；GitHub Actions：Ubuntu 24.04，日志标识 Azure eastus（美国东部）。本地公网出口地域未另行核实。
- 两端运行同一提交 `d1d44f3` 的脚本，各三轮、每轮十个栏目，每个栏目抽取一个详情页。最新文件与通知抽到同一个详情链接，共九个不同详情页。
- 所有网络请求起始间隔至少三秒；不并发、不绕过 robots、不下载附件、不做 OCR。耗时含连接与响应体读取，不含限速等待。
- 国家能源局先读取栏目 HTML，再读取该页脚本引用的公开 JSON；它不是服务器直接输出列表的页面。
- 标题、日期和链接与实际返回内容核对；日期保留来源差异。正文证据见文末。
- [GitHub Actions 运行记录与报告下载](https://github.com/gwen8316-bit/guangdong-storage-policy-radar/actions/runs/36540278569)；远程工作流执行成功不等于正文全部成功，以下按实际数据分别统计。

## 结论

两个环境的十个栏目均三轮取得 HTTP 200，并解析出标题、日期和详情链接。全部抽样详情页三轮返回 HTTP 200；九个栏目的样本可提取正文文字，一个栏目的样本是图片报表。没有发现境外 IP 拦截，建议保留 GitHub Actions 方案。

本次是同一时段内的短期检查，不能保证未来运行稳定。初步摸底时曾有一次国家能源局 robots 请求发生 TLS EOF，脚本已跳过该次详情访问；后续正式三轮没有复现。不要以短测完全无错误代替长期运行监测。
